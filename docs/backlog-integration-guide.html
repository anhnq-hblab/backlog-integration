Backlog Integration

Huong dan dung dung voi thuc te hien tai

Slide nay tom tat package backlog-integration theo implementation hien co trong repo, khong theo version “mong muon” cua workflow.

Tap trung vao 4 cau hoi: cai gi, setup gi, update ra sao, va co gi de bi ghi de.

End-user guide
Package nay la installer + config generator. No khong tu minh chay tron ven quy trinh bugfix Backlog.
Phim mui ten de chuyen slide 1 / 7
Package scope

Package nay lam duoc gi

  • Install SKILL.md va toan bo thu muc scripts/ vao tool dich.
  • Copy cac workflow markdown trong repo vao thu muc workflow/command cua tool.
  • Tao .brain/backlog.json tu thong tin detect duoc.
  • Ship cac utility scripts cho parse URL, git helper, va image download.
Khong bao gom MCP orchestration, subagent review, state resume, auto PR, auto report.
Y nghia Cac phan tren co the nam trong workflow/spec, nhung khong phai code CLI dang thuc thi.
Scope thatuc te 2 / 7
Install

Cai skill va workflow

npx backlog-integration install

npx backlog-integration install --tool codex --location global
npx backlog-integration install --tool cursor --location project-local
npx backlog-integration install --tool all --location global

Neu thieu --tool hoac --location, CLI mo interactive wizard.

Global paths Claude: ~/.claude/skills
Codex: ~/.codex/skills
Antigravity: ~/.gemini/antigravity/skills
Project-local Claude: .claude/skills
Codex: .codex/skills
Antigravity: .agent/skills

Setup

Tao config project

cd your-project
npx backlog-integration setup
npx backlog-integration setup --api-key "YOUR_BACKLOG_API_KEY"

setup detect git_host, backlog_space, project_key, sau do ghi file .brain/backlog.json.

Ghi chu Neu co .gitignore, CLI se them .brain/ neu chua co.
Mac dinh hien tai backlog_api_key la chuoi rong neu ban khong truyen --api-key.
Config generation 4 / 7
Overwrite rules

Khi nao thong tin cu bi ghi de

  • install xoa thu muc skill dich va copy lai ban moi.
  • install chi ghi de workflow cung ten; workflow cu khac ten van con.
  • install khong sua .brain/backlog.json.
  • setup ghi de toan bo .brain/backlog.json bang config moi.
Nguy co lon nhat hien nay: chay lai setup co the lam mat backlog_api_key va cac field nang cao ban da them tay.
Khuyen nghi Backup .brain/backlog.json truoc khi regenerate config.
Day la diem hay nham 5 / 7
Update

Cap nhat dung cach

npx backlog-integration@latest install

Lenh nay phu hop khi ban muon cap nhat skill/workflow da cai.

  • Skill duoc thay bang ban moi.
  • Workflow cung ten duoc cap nhat.
  • Config project giu nguyen.
Neu muon cap nhat config Ban phai chay setup rieng, va viec do khong an toan neu config da duoc custom.
Dung ky vong Update package khong co nghia la merge hay migrate config cu.
Update reality 6 / 7
Workflow vs CLI

Doc docs sao cho khong bi lech ky vong

  • README.md la noi mo ta package behavior dang co that.
  • workflows/auto-bugfix.md la workflow/spec cho runtime co du capability.
  • skills/backlog-integration/SKILL.md la bridge giua implementation package va workflow guidance.

Neu mot tinh nang nghe rat “auto”, hay kiem tra xem do la code CLI hay chi la workflow expectation.

Quy tac de nho: README = implementation thatuc te, workflow/SKILL = cach agent co the van hanh.
Hoan tat 7 / 7

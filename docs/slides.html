Backlog Integration

AI DevOps tool tự động hóa toàn bộ vòng đời bug fix —
từ phân tích nguyên nhân đến tạo PR và báo cáo Backlog.

Claude Code Cursor Antigravity Codex OpenCode

npx backlog-integration install

Vấn đề

Dev mất quá nhiều thời gian
vào quy trình thủ công

Mỗi bug fix thông thường cần developer thực hiện 7–10 bước thủ công: đọc issue, phân tích root cause, sửa code, test, tạo branch, commit, push, tạo PR, comment Backlog, update status — lặp đi lặp lại mỗi ngày.

⏱

Tốn 30–60 phút mỗi bug chỉ cho overhead quy trình, không phải thời gian suy nghĩ

🔁

Lặp lại nhàm chán: commit message, PR description, comment Backlog theo format cố định

🌐

Context switch liên tục giữa IDE, Backlog, GitHub/GitLab làm mất tập trung

📸

Screenshot bị bỏ qua — thông tin quan trọng nhất trong bug report thường là ảnh

Điểm nổi bật

Innovations Chính

📸

Image Analysis

Download ảnh từ Backlog, extract:
• Error message từ popup
• Tên UI component, label
• Route/URL từ address bar
• Visual diff before/after

Cross-check root cause với visual evidence — đặc biệt quan trọng cho frontend bugs.

🌿

Worktree Isolation

Mỗi bug fix được thực hiện trong git worktree riêng biệt.

• Không conflict khi fix nhiều bugs song song
• Dễ dàng compare changes
• Clean rollback nếu review fail
• Batch mode fix N bugs đồng thời

💬

Plain Language Comments

Comment Backlog được viết cho comtor / PM / client — không phải developer.

❌ Không: file names, code snippets, line numbers
✅ Có: triệu chứng, impact, phạm vi ảnh hưởng

Format tiếng Việt + template chuẩn theo dự án.

Cài đặt

Bắt đầu trong 3 bước

1

Install skill vào tool của bạn

npx backlog-integration install

Interactive wizard sẽ hỏi tool nào (Claude Code / Cursor / ...) và global hay project-local

2

Setup config với API key

npx backlog-integration setup --api-key "YOUR_BACKLOG_API_KEY"

Auto-detect git remote để điền backlog_space, project_key, git_host — sinh file .brain/backlog.json

3

Chạy auto-bugfix

/auto-bugfix PROJ-1234 # hoặc dán URL: /auto-bugfix https://myteam.backlog.com/view/PROJ-1234
Cấu hình

.brain/backlog.json

{ "backlog_space": "myteam.backlog.com", "backlog_api_key": "YOUR_KEY", "project_key": "PROJ", "git_host": "github", "auto_branch": true, "auto_push": true, "report_lang": "vi", // Advanced options "execution_mode": "auto", "review_layers": ["code_quality", "test_coverage", "architecture"], "review_max_iterations": 2, "batch_concurrency": 2, "lazy_fetch": true }

MCP Ưu tiên

Tool dùng backlog-mcp-server làm primary. Python scripts chỉ fallback cho binary (images) hoặc khi MCP không khả dụng

Token Optimization

lazy_fetch: true → chỉ load description/comments khi cần. MAX_TOKENS=5000 cho MCP responses. Tiết kiệm 50–65% tokens

Google Sheets Alternative

Không dùng Backlog? Dùng workflow /auto-bugfix-sheet với google_sheets.json.template — đọc bug context từ Sheets
